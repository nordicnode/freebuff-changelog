Updates included in this release (0.1.11 since 0.1.10):
- 2026-09-30 Guard against file edits cut off mid-generation: A new `truncated-write-guard.ts` module in `packages/agent-runtime/src/util` refuses two shapes of a file edit cut off mid-generation. The runtime's `parseRawToolCall` returns a truncated error when tool arguments stop mid-JSON (a bracket/string prefix that never closes), telling the model nothing was written instead of inviting a re-issue; `processFileBlock` refuses a `write_file` that would replace an existing file of 30+ lines with a copy under 60% of its size that leaves brackets open where the current file balances them. Both refusals log the new `FILE_WRITE_GUARD_EVENT` to Axiom via the allowlist added in `common/src/util/axiom-only-log.ts`, and the change adds tests and a docs section describing the guard. (touches: packages/agent-runtime/src/util/truncated-write-guard.ts, common/src/util/axiom-only-log.ts, docs/agents-and-tools.md, packages/agent-runtime/src/process-file-block.ts, and more) [notable]
