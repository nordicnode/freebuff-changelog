Updates included in this release (0.2.1 since 0.2.0):
- 2026-09-30 CLI sends terminal env and input profile in ad and run metadata: The CLI now ships a compact `v1;in=1;out=1;tp=iterm;term=1;ct=1;sz=120x40;ci=0;ssh=0;l=1;p=shell;g=terminal;osc=1 descriptor of its terminal environment under the x-freebuff-env` header on Freebuff session and ad requests, and the same descriptor plus per-prompt input counts into `codebuff_metadata` for each run. `clientEnvironmentHeaders()` is imported into `buildAdAuctionRequest` and the gravity ad path so ad requests carry env, device and trace pointers consistently, and `clientDescriptorMetadata` attaches `freebuff_client_env` and `freebuff_input_profile` to the Freebuff run config. A one-time ancestor-process probe starts at launch (reading parent and grandparent kinds, skipping the CLI's own launcher pid) and the colour-query reply is recorded, because ad networks bot-filter on the user agent while the server uses the descriptor to scope bot-filtering and billing. (touches: cli/src/utils/client-environment.ts, cli/src/utils/input-profile.ts, common/src/constants/freebuff-client-descriptor.ts, cli/src/ads/ad-request.ts, and more) [notable]
- 1 other change was left out of this list because a check discredited its summary; do not describe what the list omits.
