Updates included in this release (0.0.202 since 0.0.201):
- 2026-09-26 Codebuff own-credits 402 no longer treated as a Freebuff provider: isFreebuffProviderUsageError now short-circuits to false when the error message matches CODEBUFF_OWN_CREDITS_ERROR_PATTERN (/codebuff\.com\/usage/i), so Codebuff's own out-of-credits 402 reaches the ordinary out-of-credits flow instead of being misreported as a Freebuff provider problem. This fixes a regression in CLI lite mode where a paying user running out of Codebuff balance was told the failure was "on us, not your account". The change touches only error-classification plumbing in the CLI and the shared constant it depends on. (touches: cli/src/utils/error-handling.ts, common/src/constants/freebuff-errors.ts) [notable]
